## ✨ Design & Animation Highlights

- 📽️ **Exact Renando Cinema Aesthetic**:
  - **Fonts**: Massive `Anton` display headlines, `Caveat` handwriting manifesto script, `Manrope` editorial body, and `JetBrains Mono` code tags.
  - **Atmosphere**: Deep Obsidian Black (`#090909`), warm editorial ink (`#f2efeb`), and electric scarlet crimson (`#e32b3c` / `#ff5d65`).
  - **Film Grain Texture**: Subtle vintage cinema grain overlay across all viewports.
- 🎛️ **Interactive 3D Tilt Card**: Mouse-reactive 3D perspective tilt on the hero technical ID card.
- 🔴 **Cursor Spotlight**: Smooth radial trailing glow illuminating dark panels on hover.
- 📜 **Infinite Marquee Ticker**: Continuous seamless looping developer keywords ribbon.
- 🔢 **Animated Stat Counters**: Smooth numeric count-up animations on scroll (`40+`, `06`, `250+`, `99.9%`).
- ⚡ **Scroll Depth Progress Bar**: Glowing crimson line tracking scroll depth at the top edge.
- 🔊 **Futuristic UI Sound Synthesizer**: Web Audio API micro-haptic click and hover feedback with instant mute/unmute toggle.
- 🍱 **Production Software Grid**: Real-time search and category filtering (`ALL`, `AI & ML`, `FULL-STACK`, `SYSTEMS`).
- 🔬 **Engineering Breakdowns**: Interactive deep-dive viewer with architectural dataflow diagrams for ToolMatrix, SlideCraft, and Milo.
- 🏆 **Honors & Career Journey**: Editorial awards list and chronological experience timeline.
- 💻 **CLI Terminal Drawer**: Interactive terminal emulator (`help`, `about`, `skills`, `projects`, `sudo hire-me` with confetti).

## 🛠️ Tech Stack

- **Core**: React 18, TypeScript, Vite
- **Animations**: Framer Motion, Canvas Confetti
- **Styling**: Tailwind CSS, PostCSS, Autoprefixer
- **Typography**: Anton, Caveat, Manrope, JetBrains Mono
- **Audio**: Web Audio API Sound Synthesizer

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/SHIVA-TIWARI2403/shiva-portfolio.git
cd shiva-portfolio

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
