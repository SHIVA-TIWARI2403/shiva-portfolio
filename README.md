# ⚡ Shiva Tiwari — Modern Portfolio & AI Systems Showcase

An ultra-modern, high-performance portfolio crafted with **React, TypeScript, Tailwind CSS, 21st.dev UI architecture**, and interactive canvas micro-interactions.

🌐 **Creator**: Shiva Tiwari (Satendra Pratap Tiwari)  
📍 **Location**: Ayodhya, Uttar Pradesh, India  
🚀 **Flagships**: [ToolMatrix AI](https://shiva-tiwari2403.github.io/ai-tool-matrix/) • [SlideCraft AI](https://github.com/SHIVA-TIWARI2403/ai-student-ppt-maker) • [Milo Social](https://milosathi.netlify.app)

---

## ✨ Features

- 🌌 **Interactive Constellation Canvas**: Lightweight 60fps particle physics engine reacting to cursor hover.
- 🍱 **21st.dev Inspired Bento Grid**: Categorized project showcase (AI & ML, Full-Stack, Autonomous Systems) with real-time filters and live badges.
- 💻 **Interactive CLI Terminal Modal**: Fully functional terminal supporting commands (`help`, `about`, `skills`, `projects`, `matrix`, `sudo hire-me` with celebration confetti).
- 🎨 **Top-Tier OLED Dark Palette**: Deep space obsidian (`#030712`), cyber cyan, emerald, electric violet, and glassmorphic panels.
- ⚡ **1-Click Copy & Interactive Dispatch**: Direct mail dispatch pre-filled with project inquiries.
- 📱 **100% Responsive & A11y Ready**: Accessible semantic layout with visible focus and reduced motion support.

---

## 🛠️ Stack

- **Core**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, PostCSS, Autoprefixer
- **Icons & Effects**: Lucide Icons, Canvas Confetti
- **Design System**: 21st.dev UI tokens & Glassmorphism
