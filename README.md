# Shiva Tiwari — Personal Portfolio

Personal developer portfolio and interactive showcase built with React, TypeScript, Tailwind CSS, and Framer Motion.

Live URL: [https://shiva-tiwari2403.github.io/shiva-portfolio/](https://shiva-tiwari2403.github.io/shiva-portfolio/)

---

## Overview

A responsive single-page web portfolio featuring:
- **Interactive UI Components:** 3D perspective mouse-tilt cards, cursor spotlight illumination, and smooth scroll progress indicators.
- **Project Showcase:** Filterable software directory covering full-stack applications, developer tools, and systems projects.
- **Interactive Terminal Drawer:** In-browser CLI emulator supporting basic commands (`help`, `about`, `skills`, `projects`).
- **Typography & Theme:** Dark editorial styling with deep obsidian backgrounds, warm off-white contrast typography, and crimson accents.

---

## Tech Stack

- **Framework:** React 18, TypeScript, Vite
- **Styling:** Tailwind CSS, PostCSS
- **Motion & Interactions:** Framer Motion, Canvas Confetti
- **Audio Feedback:** Web Audio API for lightweight micro-interaction sound cues
- **Typography:** Anton, Caveat, Manrope, JetBrains Mono

---

## Local Development

```bash
# Clone the repository
git clone https://github.com/SHIVA-TIWARI2403/shiva-portfolio.git
cd shiva-portfolio

# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Build for production
npm run build
```
